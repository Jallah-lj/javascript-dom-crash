# JavaScript DOM Crash Course 🚀

Welcome to the **JavaScript DOM Crash Course** repository! This project is a practical, hands-on playground designed to teach and demonstrate the core fundamentals of **DOM (Document Object Model) Manipulation** using Vanilla JavaScript.

Whether you are a beginner looking to understand how JavaScript interacts with HTML, or an intermediate developer needing a quick reference for DOM API methods, this repository contains clean, documented examples covering everything you need.
